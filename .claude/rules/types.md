# 型定義を変更するときの注意

- `src/types/project.ts`・`src/types/log.ts`など、アプリ全体から参照される型を変更する前に、
  利用箇所を必ずgrepしてから編集する
- 型を緩めて（オプショナル化・`any`化）エラーを回避しない。呼び出し側の不整合を直す
- 現時点ではバックエンド（DB）を持たないため、型が正しいかどうかは`src/data/*.ts`の実データと
  矛盾しないことが唯一の基準になる。将来バックエンドを導入したら、テーブル定義との整合確認も
  ここに追記する
